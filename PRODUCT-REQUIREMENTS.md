# BASE GUARD — Initial Product Requirements

## Intended problem
Help a person request assistance and communicate essential incident information.

## Not yet implemented
- Sending an SOS to responders.
- GPS/location sharing.
- Calling or messaging emergency services.
- Responder dashboard.
- Offline message queue.
- User accounts or cloud storage.

## Requirements before implementation
1. Identify target users and priority emergencies.
2. Verify Malawi emergency contacts with authoritative sources.
3. Obtain agreements with any response organizations.
4. Define consent, privacy, safeguarding and data-retention rules.
5. Test false alarms, abuse, network loss and device failure.
6. Make clear what happens after a user presses SOS.
