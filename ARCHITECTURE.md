# Initial Technical Architecture

## Organization
BASE WORLD MALAWI is the parent innovation initiative. Proposed divisions:
BASE AI, BASE GUARD, BASE MEDTECH, BASE CYBER, BASE ROBOTICS, BASE SPACE,
BASE EDU and BASE SYSTEMS.

## Flagship
BASE GUARD is the first prototype, focused on emergency assistance.

## Initial layers
- Android client: user interface and consent-driven device features.
- Backend (future): authenticated API, incident records and notification service.
- Operations (future): verified response partners and incident-handling procedures.
- Governance: privacy, security, safety, accessibility and audit documentation.

## Non-negotiable safeguards
- Do not send location without clear user consent.
- Collect the minimum data needed and define retention/deletion rules.
- Encrypt data in transit and at rest when a backend is introduced.
- Restrict staff access and maintain audit logs.
- Test failure cases, low connectivity and battery constraints.
- Never claim emergency dispatch works until partners and end-to-end tests verify it.
